# Quick Achieve v2.23.70

> 「收藏这段文字」改成和 **万能框选识别图片文字 / 识图搜索** 一样的形式：横条成员，可加可移。

## 改了什么

- 设置页「横条上的引擎」里新增小节 **横条成员**，里面是一行 `.item`：
  - 图标 **★** + 名字 **收藏这段文字**；
  - 状态说明：「在横条上 · 点一下把选中的文字存进快速收藏」/「不在横条上 · 点『加入横条』把它放回去」；
  - 右侧按钮 **移出横条 / 加入横条**，和引擎那套「添加到横条 / 移出」同一个语义。
- 底层仍是配置 `fav_quick_show`（默认开）；横条按它显示/隐藏 ★。
