# Quick Achieve v2.23.49

> 剪贴板历史改成「附加功能」里的一个**子项**：点开才显示，不再一进页面就怼在眼前。

## 改了什么

| | 以前 | 现在 |
|---|---|---|
| 位置 | 附加功能页首的**常驻卡片** | 子项列表里的 **📋 剪贴板历史** |
| 显示 | 一进附加功能就看到 | **点一下才展开** |
| 结构 | 混在 extras 页里 | 独立子页 `data-pane="cliphist"` |

和「二维码解析」「文字识别」完全同一套交互。附加功能页本来就"每次进入回到第一项"（v2.10.0 你的要求），所以现在必须点一下才能看到它。

功能本身没变：默认关闭、只存本机、不参与备份 / WebDAV 同步、可一键清空、可选不落盘。
