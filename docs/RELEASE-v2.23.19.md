# Quick Achieve v2.23.19

> 保存失败会说到你面前；结果窗的三个竞态也一起修了。

## 一、保存失败现在会说到用户面前

`config::save` 现在返回**成功与否**，两处开始真正用它：

- **设置页**改任何一项，写盘失败会弹一条 toast：「这次改动重启后会回滚」；
- **恢复备份**的返回值会追加一句「⚠ 但配置没能写到磁盘」——
  以前界面照样弹"已恢复"，而磁盘上还是恢复前那份，重启就退回去了。

（磁盘满、目录只读、网盘占用、杀软拦写入，都会走到这条路。）

## 二、结果窗的三个竞态

| 场景 | 以前 | 现在 |
|---|---|---|
| 「都看」多框模式下识别失败 | 错误原因写进**隐藏的** `#text` → 你看到"一排空框 + 一条 1.5 秒就消失的提示"，而且那句错误还会被当成"识别结果"复制/翻译出去 | 写进当前可见框 |
| 「文本处理」点完还没回来，就来了新识别结果 | `setRangeText` 用的是**发起时**的选区偏移 → 处理结果插到错位置、把新结果改坏，且不报错 | await 回来先比对原文，变了就提示重试、不写回 |
| 「文本整理」失败回滚 | 无条件 `ta.value = saved` → 把期间推进来的新结果盖回旧文本 | 不再回滚（后端失败时本来就没改识别结果） |

## 三、顺手

结果窗里「复制 / 翻译 / 打开链接 / 文本处理 / 失败提示」现在统一用同一套取词口径
（多框时取当前框），不会再出现"某个按钮拿到上一张图的文字"。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> 从 v2.23.10 起，换上新 exe 后程序会**自己接管**（每 20 秒看一眼磁盘上的版本号，空闲时自动重启）。
