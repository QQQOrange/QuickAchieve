# Quick Achieve v2.23.128

> 软件引擎现在能启动本机程序并传参：欧路词典这种 `exe + 搜索词` 的查词工具，
> 可以直接放进横条或网格页，地址填自己的安装路径，参数写 `-w {query}`。

## 原因

以前「软件引擎」只接受 `协议://` 或 `file:///` 地址，`open_app` 把地址交给默认
浏览器 / 协议处理器就结束了：本机 exe 既带不了启动参数，也没法按需提权。
欧路词典这类工具必须启动 `eudic.exe -w 查询词`，所以只能放在 Quick Achieve
外面，横条和网格页都用不上。

## 新增

- 外部软件配置增加 `args`（启动参数）与 `admin`（管理员启动）两个字段；
  老配置缺字段时按空串 / false 读入，不影响升级。
- 设置页「软件引擎」表单：地址旁新增「选择程序…」（复用 `pick_app` 文件
  对话框），下面新增「启动参数」输入框与「以管理员身份打开」开关。
- 本机程序识别：裸盘符路径（允许空格）、带首尾引号的路径、`file:///C:/…`、
  UNC `\\server\share\…` 都认；保存时校验文件确实存在，路径不存在会在
  表单里直接报「找不到这个程序」。
- 搜索类占位符同时支持 `%s` 与 `{query}`，可以写在地址（网页）或启动参数
  （本机程序）里；本机程序的搜索词按 `CommandLineToArgvW` 规则加引号后，
  作为 `lpParameters` 交给 `ShellExecuteW`。
- `admin=true` 时 ShellExecuteW 使用 `runas` 动词（会弹 UAC）。
- 横条、网格页、全部引擎面板点击软件格时，搜索词优先取输入框里刚敲的字，
  其次才是划词结果 —— 以前只传划词，输入框里打的字会被忽略。

网页 / 协议软件维持原契约：地址必须以 `协议://` 开头，搜索类必须含 `%s`，
且不允许填写启动参数或管理员启动；这些限制在保存时校验。

## 欧路词典怎么配

1. 设置 → 引擎 → 软件引擎 → 添加。
2. 名字填 `欧路词典`；地址填 `C:\Program Files\eudic\eudic.exe`，或点
   「选择程序…」直接选。
3. 类型选 `搜索`；启动参数填 `-w {query}`；需要时勾「以管理员身份打开」。
4. 保存后点「添加到横条」，或到网格页把 `@app:<id>` 放进格子。
5. 横条输入框打字（或划词）后点欧路格，词会作为 `-w` 的参数传给 eudic；
   含空格的词会整体加引号，不会被拆成多个参数。

## 验证

- `cargo test --quiet`：505 tests，503 passed，2 ignored，0 failed。
- 新增单测覆盖：本机路径识别（盘符 / 空格 / `file:///` / `%20` / UNC）、
  `{query}` 与 `%s` 的搜索类型推断、`clean_app_full` 的本机 search/open 契约、
  搜索词加引号（含引号与尾部反斜杠）、`args` / `admin` 落库。
- 手动：选 `eudic.exe`、参数 `-w {query}`，在横条输入 `hello world` 点格，
  欧路词典打开并查 `hello world`，参数未被空格截断。
