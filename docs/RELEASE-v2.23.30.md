# Quick Achieve v2.23.30

> 修掉「点开更多引擎，进去还是收藏页」；另外升级后双击没反应时，程序现在会自己解释。

## 一、「进更多引擎还是收藏页」

你报的现象我确认了，是两层原因叠加：

1. **渲染指纹缓存**：`renderPanel` 靠指纹判断"要不要重建"。收藏面板换了面板内容，
   却**没有让指纹失效** —— 于是"看完收藏夹、再点 ⋯"时签名和上次一样、面板里又有内容，
   直接 return，引擎格子一个都不重建。
   v2.23.22 补过这一行，但**被后续某次改动覆盖掉了**（这轮查源码时发现已经没有了）。
2. **状态跨轮残留**：`panelFav`（当前是不是收藏面板）只在面板正常收起时清，
   而横条还可能被 Esc / 点别处 / 鼠标移远 / 后端收掉 —— 那些路径不清状态。

现在三重保险：

- 收藏面板渲染时**清指纹**（补回）+ 标一个"这块内容是谁画的"；
- 引擎面板的缓存判据加入归属检查：**归属不是引擎面板就必然重建**；
- 每一条新横条（`qs://show`）都复位面板状态 —— 和"重启之后还是收藏"彻底绝缘。

## 二、升级后双击没反应？现在会自己说清楚

排查你这个 bug 时发现：你机器上**旧进程一直占着单实例锁**，每次"重启"其实是新进程
刚起来就静默退出（日志里是 `another instance is running, exit`）—— 所以你看到的
一直是旧界面、旧 bug，包括上面这个。

现在会检测"跑的是不是已经被替换掉的旧映像"（比对进程创建时间和 exe 修改时间），
是的话弹一句：

> **Quick Achieve 有新版本在磁盘上**
> 现在托盘里运行的是升级前的旧进程，它占着只属于旧版本的通道，所以新版本起不来。
> 请：① 托盘区找到图标（可能在 ^ 里）→ ② 右键 → 退出 → ③ 再双击一次新版本。

正常双击（同一个版本在跑）仍然安静退出，不会打扰。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. **先在托盘图标上右键 → 退出**（旧进程不退，新版本起不来）；
4. 双击运行。
