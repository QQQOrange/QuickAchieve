> 设置页搜索框：**图标画错了**，加上两条只有搜到子页面时才会暴露的 bug。

## 一、搜索框前面那个"不知道是什么"的图标

原来是用**三个 CSS 渐变**拼出来的假放大镜（一个圆环 + 两根斜线）。渐变拼图标的参数随尺寸 / DPI 一变就散架，实际渲染出来只是一团东西。

现在换成真的 SVG（16×16 描边），挂在容器的 `::before` 上、用 `mask-image` 取形状、`background-color: var(--fg-dim)` 取颜色 —— 亮暗两套主题都跟得上，聚焦时还会跟着强调色变。

> 为什么不用 `background-image` 直接给 SVG：data URI 里的颜色是写死的，暗色主题下会看不见；`mask` + 背景色才是"形状归图标、颜色归主题"的正确分工。
> 也不能把 `mask` 放在 `<input>` 上 —— 那会把输入框的底色和边框一起遮成放大镜形状（我第一版就是这么错的，及时改掉了）。

**已截图确认**：设置页顶栏现在是一个正常的放大镜。

## 二、搜到「备份 / 帮助」这些子页时，分页名显示成英文 key

结果列表里那一列小字是"这一项在哪一页"。顶栏 tab 有 `data-tab`，而**子页只有 `data-sub` 的 chip**，于是子页显示成 `backup` / `help` —— 一半中文一半英文。

现在两种都查，并且把 chip 里写在文字中的 emoji（`☁️ 备份与同步`）剪掉。

## 三、跳进折叠区看到的是空白

帮助页、本地 OCR 环境那些说明都在 `<details>` 里。跳转只摘了祖先的 `hidden`，没打开 `<details>` —— 于是滚过去了，但内容是折着的。现在跳转时自动展开。

## 四、一个我追了三轮又撤回的"假 bug"（如实记录）

看截图时觉得"设置窗比屏幕还宽、版本号被切掉"，就动手按屏幕钳制尺寸。查了四轮才发现：**真实屏幕是 3840×2160**，窗口 1586×1391 物理像素只占 41%×64%，完全正常 —— 是我截的图是虚拟化后的 1920×1080，看着像被切掉。

结论：那部分改动**全部撤回**，一行不留（`git checkout` 恢复）。教训写在提交说明里：**先量，再改**；测量工具本身可能说谎（非 DPI 感知进程拿到的是虚拟坐标）。
