# Quick Achieve 桌面版

> 在任意软件里选中文字，或按下快捷键，屏幕上方会弹出一条搜索横条：点一颗图标，就把选中的
> 词交给那个网站 / 软件 / 快捷键去处理。另有屏幕文字识别（OCR）、翻译、截图识图、
> 收藏夹、图标编辑器、加密备份与 WebDAV 同步。

Windows 10 / 11 桌面应用，**原生宿主（wry + 系统 WebView2）**，无运行时装依赖。

> **体积**：单文件约 **7.6 MiB**，前端已压缩内嵌 —— 拷走一个 exe 就能跑，
> 不需要旁边的资源目录。
>
> 「AI 抠图」用到的推理运行库（`onnxruntime.dll`）与模型**不打进安装包**，
> 由你在设置里点「下载」时才下到 `<程序目录>/抠图模型/`。不用这个功能就一个都不下。

## 功能一览

| 能力 | 说明 |
|---|---|
| **划词横条** | 选中文字弹出，点图标即搜索；触发方式二选一：**选中即弹** / **按住 Ctrl 才弹**（互斥，改完立即生效） |
| **多引擎** | 内置 **777 个引擎条目**（27 个大类），支持自定义网页引擎 / 软件直达 / 快捷键引擎 |
| **经典别名** | 大量引擎带别名，搜「B站」能找到哔哩哔哩、「度娘」找到百度 |
| **截图识图** | 框选屏幕区域 → 多家识图引擎（百度 / Yandex / SauceNAO / trace.moe / AI 视觉模型） |
| **文字识别 OCR** | 框选读字，**本地离线引擎 + 十多家在线引擎**；可多引擎同时识别，结果窗带**每家排队 / 识别中 / 完成·用时 / 失败**的状态条 |
| **翻译** | 横条上直接翻译选中内容，支持流式输出 |
| **收藏夹** | 两级目录，文字 / 图片 / 富文本，可拖拽排序 |
| **智能直达** | 只录一个地址，自动认出是软件 / 网址 / 文件；自动填备注与图标，钉到横条上点一下就打开 |
| **双弹层** | 划词弹细横条、按快捷键（默认 **Ctrl+Shift+G**）弹**网格页**——行列 / 单元格尺寸 / 内容各自配置，互不干扰；两类都支持**按应用绑定**（某个软件单独一套，没配就用默认） |
| **网格页编辑** | 编辑态点格子不执行只编辑；**长按 0.4 秒直接把格子拎起来拖动换位**，其余格子让位、松手保存（鼠标 / 触屏同一套手感）；拖到**左右边缘停 0.4 秒**就把它送到相邻页末尾 |
| **一键多模型** | 「添加到这一格」里可给文字识别 / 识图 / 翻译选**多家模型并行**，每家各出一段结果 |
| **框选直接执行** | 从哪个入口进的框选就只做哪件事 —— 点 OCR 就识别、点识图就搜图、点二维码就读码，**框完立刻执行，不再弹一条横条问你要哪个** |
| **万能框选** | 想"先框再决定"就加这颗格子（横条、网格页都能放）：框完弹出**识别 / 翻译 / 识图 / 二维码 / 复制图片**，挑一个再执行（**复制图片**只在这条路上有） |
| **快捷键独占** | 录的热键和别的软件撞车时，**只激发本软件** —— 系统的、别家的同一个组合都收不到这次按键（在低级键盘钩子里截住）；默认开，可关。`Ctrl+Alt+Del` / `Win+L` / `Win+Tab` 这类系统保留键拦不住 |
| **Shift 多选并行** | 横条上 **Shift+点击**只是打勾（不执行、不收条），普通点任意一颗就把勾上的**合并成一次**跑 —— 同一段字同时拿几家的结果，不用重新划选 |
| **长按拖动重排** | 横条上按住任意一颗约 0.3 秒即可拖走换位，其余格子自动让位、松手即存；分隔线也能拖，拖完那一下不会误执行。**拖出横条**松手 = 移出这一颗（移出前会先变红） |
| **悬停提示** | 鼠标在图标上停 0.16 秒即浮出名字（系统自带那条要等 1 秒）；自绘的独立小窗，跟着明暗主题走，拖动时不打扰 |
| **拖拽配置** | 设置 →「横条上的引擎」：把「全部引擎」里任意一行**直接拖进来**，松手就插在落点位置；已在横条上的行拖过去只改位置，不会重复添加 |
| **右键最近用过** | 横条空白处右键弹出「最近用过」（最多 6 条），点一条就用当前这段文字执行它；面板展开时不打扰 |
| **包裹符号** | 选中文字一键套成 “” 《》 【】 `[ ]` `{ }` 等成对符号；同一组再点一次拆掉，换一组是替换外层，结果直接复制 |
| **图标编辑器** | AI 自动抠图（可选模型）+ 涂抹修饰 + 换模型重抠 + 导出 |
| **自定义图标** | 任意引擎 / OCR / 翻译 / 收藏夹条目都能换成自己的图，**换新版本自动继承** |
| **备份与同步** | 本地加密备份（AES-256-GCM + Argon2id）、WebDAV 云端同步 |
| **自动更新** | 「关于」里可勾选自动检查；发现新版在程序内下载、校验、替换 |
| **主题** | 亮 / 暗 / 跟随系统，横条支持液态玻璃（WebGL2 真折射） |

## 下载与安装

1. 到 [Release 页面](https://github.com/QQQOrange/QuickAchieve/releases/latest) 下载 `QuickAchieve.exe`。
2. 放到你喜欢的目录（建议单独一个文件夹），双击运行。
3. **首次运行没有窗口**，程序常驻托盘 —— 在任务栏右下角的托盘区（可能折叠在 `^` 里）找到它的图标。

不需要安装程序，不需要 .NET，也不需要另装 WebView2（Win10/11 一般已内置）。

### 数据放在哪

便携式：配置、图标、日志都在 exe 同级的 `Quick Achieve data\` 里，备份在 `Quick Achieve back\`。
把整个文件夹拷到另一台机器就能接着用（**备份密码另见下**）。

## 快速上手

1. **划词**：在任意软件里选中一段文字，横条自动弹出 → 点图标搜索。
2. **快捷键**：`Ctrl+C` 取词弹横条（可在设置里关）；`Ctrl+Shift+G` 唤出**网格页**（格子面板，可自定义快捷键、行列、格子大小与内容）；`Ctrl+Alt+O` 框选识别。两者内容与样式完全分开，详见 [帮助](docs/HELP.md)。
3. **文字识别**：点横条上的 OCR 按钮（若已自定义图标，显示的就是你自己那张图）→ 框选屏幕区域。
4. **进设置**：双击托盘图标，或右键托盘图标 → 设置。

## 数据安全

- **配置文件本身是加密的**：以 `{"qsEnc":1,"kdf":"argon2id",…}` 信封保存，密钥由本机 DPAPI 保护。
- **备份可加密**：设置备份密码后，导出的 `.QuickAchieve` 备份可在别的机器上恢复 —— **密码丢了就解不开**，请自行保管。
- **智能直达也在同步范围里**：它和别的配置项存在同一份配置里，本地备份、WebDAV 同步都会带上；
  手工导出时对应分组是「智能直达」（**默认不勾选**，因为路径会暴露本机目录结构）。
- **换机器**：优先用「备份 → 导出 + 恢复」，而不是直接拷 `config.json`（后者依赖本机密钥）。

## 从 1.x 升级

- **配置与备份格式完全兼容**：1.5.x 的 `config.json`、`.QuickAchieve` 备份可直接被当前版本读取与恢复。
- 数据目录位置不变（仍是 exe 同级的 `Quick Achieve data`），所以覆盖 exe 即可，不需要迁移。
- **自定义图标会自动继承**：新版首次启动会从旧安装读取你的图标覆盖表。
- 本版把默认 OCR 引擎改为**本地引擎**（在线引擎按量计费，避免误耗额度）；需要在线识别可在设置里自行切换。

## 构建（本仓库）

本仓库就是**原生宿主本体**（`wry` + `tao`，取代 Tauri 运行时）加前端资源；Release 里的发布产物就由它构建。

```powershell
cargo test             # 单元测试
cargo clippy           # 静态检查
cargo build --release  # 产物：target\release\QuickAchieve.exe
```

发布配置见 `Cargo.toml` 的 `[profile.release]`：`opt-level` + `lto="fat"` +
`codegen-units=1` + `strip=true`。

### 自动更新怎么测

「发现新版 → 下载 → 校验 → 替换正在运行的 exe」这条链不能等真版本，所以留了两个
run-and-exit 探针和两个仅测试用的地址逃生口（`QS_UPDATE_API` / `QS_UPDATE_WEB`）：

```powershell
$env:QS_UPDATE_API = 'http://127.0.0.1:8731/api/repos/x/releases/latest'
$env:QS_UPDATE_WEB = 'http://127.0.0.1:8731/web/releases/latest'

QuickAchieve.exe --update-probe     # 只查一次，输出 NEWER/TAG/SIZE/SHA
QuickAchieve.exe --update-install   # 真下载 + 真替换（只在隔离目录里跑）
```
