# Quick Achieve v2.23.10

> 这一版是**全盘审计**的产物：修掉自建运行时层的三个硬伤（其中"点选文件 = 界面冻死"是会让人以为软件坏了的那个），
> 让新版装好会自己接管，并把帮助页 / 文档里 25 处与实现不一致的地方全部对齐。

## 一、新版装好了却不生效 → 现在自动接管

这台机器上的程序是**管理员权限**在跑，普通权限杀不掉；而换新版的做法是"旧 exe 改名、新 exe 拷回原路径"，
进程本身还在跑旧代码。

结果：新版 16:52 就部署好了，你那边**一直跑着 13:35 启动的旧版本** —— 你报的问题其实是旧版行为，
我这边怎么都复现不了，白折腾了好几轮。

现在程序每 20 秒看一眼**磁盘上 exe 的版本号**，和自己的对不上就在**空闲时**自动交班重启
（新进程带 `QS_TAKEOVER=1`，会等单实例互斥体让出来，不会出现"两个实例打架"）。

- 横条开着、框选遮罩在、拾取器在 → 算"忙"，绝不打断你；
- 启动后先等 45 秒（避开建窗、装钩子那段），之后每 20 秒看一次；
- 只比 `主.次.修订`，不比 build 号。

## 二、选文件 / 选目录会把界面堵死 2~5 分钟（最严重的一条）

`run_on_main_thread` 原来**只投递、从不内联**。而命令本身就在主线程的 `drain_ipc → run_ipc`
调用栈里同步跑 —— "先投递一个弹框任务、再自己阻塞等结果"，就是**自己等自己**：
那个 Job 永远轮不到，对话框永远不弹，界面完全不重绘。

用户看到的：点「选择应用 / 挑图标 / 选模型目录 / 选备份目录」→ **整个软件冻住**，
2~5 分钟后弹回"已取消"；收藏夹「添加图片」那条**没有超时**，直接永久冻死，只能任务管理器杀。

修：`run_on_main_thread` 在主线程上**当场执行**（恢复 Tauri 语义）；那条无超时等待也加了 120 秒兜底。

## 三、翻译 / 重新识别期间一个 CPU 核满载

`JoinHandle::poll` 拿不到结果就 `wake_by_ref()` 立刻自唤醒 → `block_on` 马上重 poll → 一轮轮空转。
改成"睡 5ms 再看"，CPU 降到接近 0。

## 四、全屏框选遮罩关不掉（强杀兜底是死代码）

`hard_close_region` 用"窗口 label 还在不在"判关没关，而 `close_window()` 会**同步**摘 label ——
第一次查就"已关闭"，永远走不到后面的 Win32 强杀。后果：主线程卡住时按 Esc、或 30 秒总闸触发，
日志写"已关闭"，**遮罩还铺在屏幕上吃鼠标**，用户满屏点不动只能杀进程。
修：判据换成 `REGION_HWND` + `IsWindow`。

## 五、主线程 panic 现在会留日志

以前 panic hook 只写一个默认不落盘的 trace —— 主线程一 panic 就是"程序突然没了"，日志一片空白。
现在同时写 `log.txt`（异步 + 同步各一次）。

## 六、穿透浮层会让"选中文字"整条链路失败

日志里发现：拖选落点常常是一个第三方工具窗（`HwndWrapper[MouseWheelEnhancement.App…]`）。
我们拿它的 pid 当"选词目标"，和前台浏览器对不上 → 判定"前台已经换人" → **连 Ctrl+C 都不发** →
在浏览器里选了一整段文字，什么都不弹，日志里还看不出原因。

修法：鼠标底下的窗口如果是**点击穿透 / 分层工具窗 / 纯工具窗**，就当它是盖在上面的浮层，
改用**前台窗口**来认"这次选词属于谁"。真实窗口的判定（比如"是不是落在横条上"）不变。

顺带堵一个危险口子：**终端判据**以前只看鼠标底下那个窗口。浮层盖在终端上时，我们会把 Ctrl+C
发到下面的终端里 —— 那是**中断信号**，会把正在跑的编译/脚本直接杀掉。现在两个窗口都会查。

## 七、设置页的两处"开了却没生效"

| 问题 | 现象 |
|---|---|
| **「默认以管理员身份运行」显示开、实际不提权** | 便携构建把 fallback 钉死成 false，界面却显示配置默认值 true → 全新安装勾着却以普通权限跑。微信 / QQ 是管理员权限，UIPI 让普通权限进程的全局钩子收不到它的输入 —— **在微信里划词不弹条、快捷键也不灵**，而开关明明是开的。现在首次启动按配置默认值决定并**立刻写进 `elevate.pref`** |
| **「没取到文字就不弹」默认值三处打架** | `Config::default()`=关、serde=开、前端=开 → 全新配置弹空横条、老配置不弹。统一成**开** |

顺带：恢复备份后界面语言不回来（`apply_view` 漏了 `uiLang`）、横条在配置到达前会少一颗识图入口
（`bar.js` 用了 `!!CONF.x` 而不是 `!== false`）、两个开关缺省显示成关（`SWITCH_DEFAULT` 补两条）。

## 八、帮助页 / 文档 25 处对齐实现

审计逐条核对了「设置页帮助 / 英文帮助 / README / docs/HELP.md」和代码，修掉其中**与实现不符**的：

| 之前写的 | 实际 |
|---|---|
| 托盘菜单 = 打开设置、立即备份、开始识别、退出 | 设置… / 暂停使用 / 截图识别文字 / 立即同步到云端 / 打开配置目录 / 退出 |
| 「结果窗固定在默认引擎」：同时识别多家时停在默认档 | r78 起多家一律并排多框；这个开关只管"只跑一家" |
| `.qsconf` 一律不加密、导入只吃明文 | 支持「加密导出」；勾隐私项强制加密并锁死；加密文件导入要密码 |
| Ctrl+C 可在「通用 → 触发」关掉 | 那颗开关原标签叫「按快捷键弹出网格页」，实际只管 Ctrl+C 取词 —— 已改名 |
| 把鼠标移到格子边缘、或按住空格拖动可移动横条 | 没有这个功能（已删掉这句） |
| 通用 → 应用范围 / 横条样式 / 预览 / 快捷键独占 | 范围 / 横条外观 → 横条外观 / 横条外观 → 预览 / 网格页 → 功能 |
| 780+ 引擎、识图"三家"填图片地址、附加功能 8 项、添加内容"分三块" | 777 引擎、两家、10 项、8 组平铺 |
| 数据目录一律 `%APPDATA%\QuickAchieve` | 便携优先（exe 同级 `Quick Achieve data\`），写不进去才退回 |

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> ⚠ 如果软件正在运行，Windows 会拒绝覆盖。先退出（托盘右键 → 退出），再替换。
> **这一版需要你手动重启一次**（正在跑的那个进程里还没有"自动接管"这段逻辑）；
> 从这版之后，以后再换新 exe 它会自己接管，不用再管。
