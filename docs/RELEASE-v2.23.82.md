# Quick Achieve v2.23.82

> 修好横条「自己收起」的两条：指针在横条上移动不再被当成"没操作"，
> 指针移远后收起也更快、更有迹可循。

## 一、指针在横条上移动，不再被 5 秒计时收走

- v2.23.79 为了防止"鼠标只是从横条旁边划过去，横条就永远不收"，把
  `pointermove` 从"重置无操作计时"里整个拿掉了；
- 结果把「指针压在横条上找按钮、来回移动」也一起误伤：还没点下去，
  5 秒一到照样收走 —— 用户报的「鼠标移动一定范围内，横条自动消失」；
- 现在只在指针**确实位于横条上**时，`pointermove` 才重置无操作计时
  （150ms 节流）；全局范围的鼠标移动仍然不算"操作"，保留 v2.23.79 的意图。

## 二、「鼠标移远就收起」更快、可诊断

- 越过阈值后的连续离开时间：**0.9 秒 → 0.6 秒**；
- 刚弹出的宽限期：**0.6 秒 → 0.4 秒**；
- 新增日志，排查时能直接看出是哪一步没发生：
  - `bar-away: 指针离横条 Xpx（阈值 Ypx）—— 开始计时，连续 600ms 后收起`
  - `bar-away: 指针连续 Xms 离横条 Ypx（超过 Zpx）—— 收起横条`
- 设置页文案更正：阈值是「指针离**横条**」的距离（原写"离弹出位置"），
  并且是「约半秒后收起」（原写"立刻收起"）。

## 三、说明：阈值默认 400px

- 设置 → 通用 → **鼠标移远就收起** 可以在 0–1000px 之间调；
- 0 = 不收起；
- 这个值决定"指针离横条多远才算走开"，改小会更灵敏；
- 无操作自动收起（默认 5 秒）仍然独立生效。
