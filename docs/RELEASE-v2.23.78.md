# Quick Achieve v2.23.78

> 「收藏这段文字」不再在横条成员列表上方单独占一块特殊提示；它和
> 识图搜索 / 识别图片文字 / 翻译 / 万能框选一样，按普通横条成员的
> 「＋ 加进横条」入口行展示。

## 一、设置页「横条成员」统一

- 去掉列表上方的独立 `#favQuickList` 区块（以前未加入横条时，它会
  单独显示一行「收藏这段文字 / 点击加入横条」，视觉上挂在百度上方，
  和其它成员不是同一套）；
- 「收藏这段文字」未加入横条时，改为和 OCR / 识图 / 翻译 / 万能框选
  完全同款的 `.item.add-row` 入口行：同一个图标位、同一段说明、
  同一颗「＋ 加进横条」按钮；
- 加入横条后，它照常作为普通成员行显示，可拖动排序、换图标、移出；
- `@favquick` 纳入内置功能哨兵表，图标统一为星标，不再落到字母/点状
  兜底；`qsFuncIcon` 也认它，预览、设置列表、横条三处一致。
