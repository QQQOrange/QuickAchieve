# Quick Achieve v2.23.80

> 网格页「智能直达」新增「最近剪贴板」格子：点一下就把剪贴板里最新那条
> 内容按类型打开。同时修复「翻译从横条移出后，重启又自己回来」的问题。

## 一、网格页：智能直达 · 最近剪贴板

- 「网格页 → 编辑 → 点空位 → 添加到这一格」里的 **智能直达** 分组现在
  **始终出现**，并且第一项固定是 **最近剪贴板**；
- 把这一格加进网格后，点它会读取剪贴板里最新一条记录，并按类型打开：
  - **网址 / 网页**（含带协议的链接、`www.` 开头的裸域名）→ 系统默认浏览器；
  - **文件夹** → 资源管理器打开；
  - **文件** → 用该文件关联的默认程序打开；
  - 资源管理器里 **Ctrl+C 复制的文件 / 文件夹**（`CF_HDROP`）同样支持，
    多选时打开第一个；
- 三类都不是时**不会假装成功**，横条上会提示：
  「不是 文件、文件夹、网址，无法打开」，网格保持展开，方便换一条再试；
- 剪贴板为空时提示「剪贴板里没有内容」；
- 图标是一枚「剪贴板 + 打开箭头」的内联线稿，亮暗主题都清楚；也支持
  用户换图标（`overrideIcons['@clipgo']`）。

## 二、修复：翻译移出横条后重启复活

- 根因：`ensure_trans_bar_sentinel` 每次启动都跑，只看「翻译总开关」，
  于是用户点「移出」之后，下次启动又往 `bar_list` 里补回 `@trans`；
- 现在和识图按钮（`img_add_to_bar`）同一套：新增 `trans_add_to_bar`
  记住「用户是否要它在横条上」——移出记 false、加回记 true，启动迁移只认这个；
- 老配置一次性推断：升级后第一次启动时，如果横条上没有 `@trans`，就认为
  **用户早就移出过**，不会在升级后被偷偷加回来（看完就再不会跑）；
- 「翻译」总开关关闭时仍会把 `@trans` 从横条摘掉；重新打开时只在用户
  没主动移出过的情况下才补回；
- 该偏好也会跟着配置导出 / 导入 / 备份走。

## 四、说明

- 「最近剪贴板」只读取**当前剪贴板**（也就是最近一条复制记录），不依赖
  「剪贴板历史」开关，也不需要开启任何额外功能；
- 这一格目前只在网格页里提供，不占横条位置。
