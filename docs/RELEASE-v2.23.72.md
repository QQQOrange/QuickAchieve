# Quick Achieve v2.23.72

> 修「收藏这段文字」的三个怪现象：未命名功能 / 同一页出现两处 / 位置跑到最前面。

## 1. 重加回横条变成「未命名功能」

`qsDisplayName` 不认识 `@favquick`，落到兜底的「未命名功能」。已在 `shared.js` 里登记：
`@favquick` → **收藏这段文字**。

## 2. 同一页面出现两处收藏

设置页原来既有独立的一行（`#favQuickList`），又因为 `@favquick` 进了 `bar_list` 而在成员列表里出现一次。
现在：**在横条上时只显示成员列表里那一行**（独立那行隐藏）；不在横条上时，独立那行才出现，作为「加入横条」入口。

## 3. 位置跑到百度上面

一次性迁移原来用 `insert(0, …)`（插到最前面），现在改成 `push`（追加到末尾）——重加回来也是排在最后，和 `toggle_bar_engine` 的行为一致。
