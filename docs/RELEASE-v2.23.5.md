# Quick Achieve v2.23.5

> v2.23.4 里"查到但没修"的 4 项，这次一次清完；另加一个查那条时顺手发现的竞态。

## 修掉

| 项 | 原来什么样 | 现在 |
|---|---|---|
| **二维码结果窗按 Esc 会丢** | 「重新框选」会把结果窗藏起来，取消时本该还回来 —— 但全局键盘钩子的 Esc 兜底直接 `hard_close_region`，绕过了 `ocr_cancel` 里那段。钩子通常**先于**页面拿到 Esc，于是结果窗凭空消失，只能再框一次 | 抽出 `cancel_region_flow()`（清句柄 + 关遮罩 + 还原结果窗），`ocr_cancel` 和 `hard_close_region` 都走它 |
| **提交后"5 秒无心跳就关窗"失效** | 判据是 `REGION_BEAT == 0`，可它只会被写成非零时间戳；页面提交时 `stopBeat()`，这条硬兜底就再也不成立了 —— 遮罩要等 30 秒总闸 | 判据改成"最近一次心跳距今 > 5 秒"（`region_beat_stale()`，带单测）；时钟回拨按"刚跳过"处理 |
| **上一轮的看门狗会杀掉新遮罩**（查上面那条时发现） | 看门狗只认窗口名。用户关掉再立刻重开时，上一轮的线程在新窗口上继续跑，而新窗口心跳还是 0 → 被判"页面没活"强杀 | 每次开窗领一个 `REGION_GEN` 轮次号，看门狗每轮先比号，不是自己那一轮立刻退出 |
| **`MODE === 'app'` 整套分支是死代码** | 点选程序早就走 `picker.html`，这段永远不执行，却让人以为 region 还兼着点选 | 删分支、删 `app` 的提示语、删 `bail` 里只为它写的那段注释 |
| **尺寸标签竖直方向没夹** | 框贴着屏幕底部时，「宽 × 高」掉出视口 | 四个方向都夹 |

顺带：`region.html` 里"90 秒总闸"的说法改成实际的 **30 秒**；`lastAct` 的注释改成
"上次**执行过**的动作"（非停留模式的自动提交也会记账 —— 这是想要的，常用哪个就在
`@any` 的动作条上高亮哪个）。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> ⚠ 如果软件正在运行，Windows 会拒绝覆盖。先退出（托盘右键 → 退出），再替换。
