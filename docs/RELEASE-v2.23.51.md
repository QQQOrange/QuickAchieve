# Quick Achieve v2.23.51

> 修：右键落在**引擎图标**上时，弹的是「更换这个图标」而不是「更多引擎」。

## 规则（按你的口径改定）

| 状态 | 右键落点 | 结果 |
|---|---|---|
| 面板**没开** | 横条上**任何**地方（含引擎图标） | **出「更多引擎」页** |
| 面板**开着** | 某个引擎图标 | 换图标 / 固定到横条的菜单 |
| 面板**开着** | 横条空白处 | 什么都不做（不重开、不跳滚动位置） |

上一版我先判"落点是不是引擎"，于是右键图标就走了引擎菜单——想开更多引擎页却得到改图标菜单。现在判据改成**先看面板状态**，再看落点。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 托盘图标右键 → 退出；
3. 覆盖 → 双击运行。
