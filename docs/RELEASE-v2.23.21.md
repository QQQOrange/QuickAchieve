# Quick Achieve v2.23.21

> 「识别中不许再点」原来是死代码；翻译窗的配置广播会"旧名单覆盖新名单"。

## 一、"识别中不许再点"从来没生效过

`setScanning()` 这套保护**只被自检调用过** —— 生产路径里一次都没跑：

- 点完「重新识别」，还能顺手再点一次 → 同一张图**并发跑两次 OCR**
  （多打一次网络请求、多跑一次本地识别），最后留在框里的是后返回的那一次；
- 截图区的"识别中"扫描动画从来不出现，看着像没反应。

现在「重新识别」和五颗文本整理按钮都真正进入扫描态：期间互相禁用、动画出来、结束后复位。

## 二、翻译窗的配置广播会"旧名单覆盖新名单"

`qs://config` 处理器可重入，而它里面要 `await` 两次 IPC。两次广播交错时，
**先发的慢响应可能后到** —— 于是刚在设置里加的一家引擎没进来、删掉的又出现了，
而且界面不会自己纠正（除非再改一次设置）。

现在加了序号，回来时不是最后一次就直接丢掉。

## 三、托盘提示函数里的死代码

`set_tooltip` 原来三次独立加锁 + 一段"拷一份又丢掉"的死代码，读起来像在换图标，
其实只更新提示文字。收成一次加锁。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> 从 v2.23.10 起，换上新 exe 后程序会**自己接管**（每 20 秒看一眼磁盘上的版本号，空闲时自动重启）。
