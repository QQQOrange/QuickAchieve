# Quick Achieve v2.23.3

> 框选这块重新分工：**打开哪个就只做哪个**；想"先框再决定"的，给你一颗**万能框选**。

## 问题

前两版的框选流程是：松开鼠标 → 停一下 → 弹动作条问"要识别 / 翻译 / 识图 / 二维码 / 复制图片"。

用 OCR 的时候，你已经点过 OCR 了，框完再问一遍是多余的 —— 用户原话：

> 我通过文本识别功能，就只要文本识别功能就可以了，不要识图，不要翻译，也不要二维码。
> 需要相关的功能，我会特别打开的。

但那条动作条本身是有价值的（一次框选能拿去做几件事），所以不是删掉，而是**挪到一个独立入口**：

> 可以设置一个万能框选，框选之后就会像现在一样提示你要识图还是要识别文字，
> 还是要翻译，还是要做二维码的相关功能。

## 现在的行为

| 入口 | 框完之后 |
|---|---|
| **文字识别**（OCR 格子 / `Ctrl+Alt+O`） | **直接识别**，不弹动作条、不问你第二遍 |
| **识图搜索** | 直接按图搜索 |
| **二维码** | 直接读码 |
| **万能框选**（新） | 弹出动作条：识别 / 翻译 / 识图 / 二维码 / 复制图片，挑一个再执行 |

## 万能框选（新功能格）

它是一个和「文字识别 / 识图 / 翻译」**同级**的功能格，不是在某个角落里的开关：

- **能加进横条**：设置 → 引擎 → 横条上的引擎 →「＋ 加进横条」。加进去之后位置可拖、图标可换、可移出，和别的功能格完全一样；
- **能加进网格页**：网格的「添加内容」→ 内置功能 → 万能框选；
- 图标是一枚「四角选框 + 两条横线」，并排放在 OCR 徽标、二维码旁边也分得清；
- **「复制图片」只在这条路上有** —— 把框住的区域当图片直接进剪贴板（贴到聊天窗口 / 文档里，格式不丢）。

想改图标？和别的格子一样：设置里那行点「换图标」，或用图库 / 自己画的。

## 顺便

- 设置项 `regionHold` → `regionAdjust`，语义也反过来（现在 `true` 才停）。
  键名换了之后，老配置里那个 `regionHold: true` 会被当成未知键忽略 ——
  所以升级后**默认就是"框完直接执行"**，不需要任何迁移。
- 设置里那一行现在叫「**框选后可调整 / 换用途**」，默认关。
  打开之后，OCR / 识图 / 二维码那三颗也会停下来给你微调（拖角改大小）——
  不打开就是各自直接执行。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> ⚠ 如果软件正在运行，Windows 会拒绝覆盖。先退出（托盘右键 → 退出），再替换。
