# Quick Achieve v2.23.86

> 修复「鼠标移远就收起」：距离以前是相对**看不见的窗口外框**算的，所以
> 阈值设成 40px 时，实际要离开可见横条约 88px 才会触发 —— 看起来就像
> 没生效。现在改成相对**看得见的横条**算。

## 问题在哪

横条窗口四周有一圈透明留白（投影 / 绘制边距）。实测：

- 窗口外框：`298 × 162`
- 可见横条：`202 × 66`

外框比胶囊**每边大 48px**。`bar-away` 一直拿外框算距离，用户把阈值调成
40px，实际要离开胶囊边缘约 `48 + 40 = 88px` 才会计时；鼠标只在横条旁边
挪一小段时，算出来的距离仍然是 0，永远不会收。

## 改了什么

- `spawn_bar_away_guard` 的距离基准从 `outer`（窗口外框）改成
  `inner`（可见横条矩形）；
- 面板展开时 `inner` 会包含面板，所以指针在面板里、贴着面板拖动仍然
  不算"走开"；
- 日志口径不变，排查时仍然能看到：
  - `bar-away: 指针离横条 54px（阈值 40px）—— 开始计时，连续 600ms 后收起`
  - `bar-away: 指针连续 632ms 离横条 … —— 收起横条`
- 现在 **40px 就是离可见横条 40px**，不再被那 48px 的透明边距吃掉。

## 说明：两条自动收起是独立的

- **鼠标移远就收起**：`设置 → 通用 → 鼠标移远就收起`（0 = 不收起）；
  越过阈值后约 0.6 秒收起；
- **无操作自动收起**：默认 3–5 秒没有任何点击/按键就收；
- 觉得还不够灵敏，可以把「鼠标移远就收起」调到 20 或 10。
