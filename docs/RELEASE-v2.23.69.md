# Quick Achieve v2.23.69

> 设置页「横条上的引擎」里，把那一行改成准确的 **★ 收藏这段文字**（带图标、带开关）。

## 说明

「收藏这段文字」是横条上的**固定按钮**，不在引擎目录里（后台没有对应条目），所以它不会出现在引擎列表 `barList` 中。这版在列表上方给它单独一行：

- 图标 **★** + 名字 **收藏这段文字**；
- 说明：横条最左边那颗星，点一下就把当前选中的文字存进「快速收藏」，不占引擎位；
- 右侧开关控制它显示/隐藏（配置 `fav_quick_show`）。
