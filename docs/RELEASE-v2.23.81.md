# Quick Achieve v2.23.81

> 网格页那一格正式改名 **「智能直达」**；同时把 Ctrl+C 彻底交还系统和目标
> 程序 —— 不再读剪贴板、不再弹条、不再注入；智能直达本身也修了「有时候
> 点了没反应」的时序问题。

## 一、改名：智能直达

- 网格页「编辑 → 点空格子 → 智能直达」里的那一项，显示名从
  「最近剪贴板」改成 **「智能直达」**（格子标题、选板条目、设置页说明
  全部统一）；
- 行为不变：点一下打开剪贴板里最新那条内容 ——
  网址 → 浏览器、文件夹 → 资源管理器、文件 → 默认程序；
  资源管理器里 Ctrl+C 复制的文件 / 文件夹同样支持；
- 三类都不是时仍然提示「不是 文件、文件夹、网址，无法打开」。

## 二、Ctrl+C 彻底交还系统和目标程序

- **移除**了 v2.23.77 加的「复制链接后弹直达条」整套功能（钩子分支、
  后台读取、配置项 `copyUrlBar`、设置页开关、导出项一起删）；
- 现在按下 Ctrl+C：**不读剪贴板、不发任何键、不弹任何条**，
  复制完全由系统和目标程序完成；
- 取词时的模拟复制也加了一道保险：**用户还按着 Ctrl / Alt / Win 时
  绝不注入 Ctrl+C**（他很可能正在自己复制 / 用组合键，避免"被劫持"的
  手感）；
- 终端类窗口（conhost / Windows Terminal / OpenConsole 等）依旧
  绝不发 Ctrl+C（那是中断信号，不是复制）。

## 三、智能直达更稳（「有时候不能实现」）

- **一次开剪贴板读全**：同时取文件列表和文本。以前分两次开门，目标程序
  正好在分段写剪贴板时会出现「文件没读到、文本也没有」的空窗；
- 读不到时重试窗口从 80ms 加长到约 250ms，并再补读一次；
- 打开失败不再被当成成功：
  - 文件没有关联程序 / 找不到路径 / 资源管理器启动失败 → 横条明确提示；
  - 网址启动失败 → 提示「打开网址失败：…」；
  - 剪贴板被别的程序长时间占着 → 提示「剪贴板被别的程序占着，稍等一下
    再点这一格」；
- 失败时把剪贴板格式表写进日志，方便以后排查「为什么这次没认出来」。
