# Quick Achieve v2.23.26

> 首次安装终于会"说话"了；另外修掉一个每次保存都在偷偷解密的性能坑。

## 一、全新安装"双击之后什么都不发生"

这个软件**没有主窗口** —— 双击图标之后屏幕上什么都不出现，只有任务栏角落多个托盘图标。
以前的处理是……什么都不做（全仓库搜不到任何 first-run 逻辑）。新用户很容易以为
"没装上"或者"装坏了"。

现在**第一次运行**会：

- 托盘弹一个气泡，把三个最常用的操作说清楚：选中文字弹横条 / Ctrl+Alt+O 截图识别 /
  右键托盘图标打开设置；
- **顺手打开设置窗口**，让你至少看到"它确实起来了"，也能当场配引擎。

只做这一次：判断依据是"数据目录里原本没有 `config.json`，而且也没从任何备份恢复"。
从旧备份恢复出来的配置**不算**全新安装，不会被打扰。

## 二、每次保存都在解密所有备份

轮转逻辑要给每份旧备份算"完整度"——**把每一份读出来解密**。而它跑在**每一次 `save`** 里
（改一个设置就一次）。实测跑在 27 份备份的目录上：一次保存解密 27 次、日志刷 27 行"已解开"——
拖滑块那种连续保存的场景直接卡。

现在先做一个廉价的目录列举：**份数没超过上限就直接返回**，一份都不读。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 现在会弹气泡并打开设置页。

> 从 v2.23.10 起，换上新 exe 后程序会**自己接管**（每 20 秒看一眼磁盘上的版本号，空闲时自动重启）。
