# Quick Achieve v2.23.66

> 横条 / 网格自动明暗：跟着**当前页面**换皮，**忽略视频**。

## 判据（新模块 `src/autotheme.rs`）

1. 以光标为中心取 420×260 的一块（横条要叠上去的那片内容）；
2. 连续抓 **5 帧**，间隔 55ms；
3. 逐像素比帧间差：任一通道**变化 > 16** 的点算"在动"（视频/动画/滚动），**整块丢掉**；
4. 稳定像素取**中位数亮度**：≥0.56 判浅色、≤0.44 判深色；灰区或稳定像素 <25% 就**不猜**，落回系统偏好。

视频亮一下暗一下不会再把横条带跑；只有静态 UI（网页背景、软件界面）参与判断。

## 接入

- 新增主题选项 **「跟随页面」**，并且是新的默认值；
- 老配置里还是 `system`（没显式选过亮/暗）的，一次性迁到 `page`；显式选过亮色/暗色的不动；
- 横条与网格共用同一套 `qs-dark` 皮肤，网格自动跟着变。
