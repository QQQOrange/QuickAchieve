# Quick Achieve v2.23.8

> **没选中文字就不弹横条。** 这次查到的是两条来路，都堵上了。

## 问题

用户报：「当前没选中文字也会弹出横条，要修复」。

| 来路 | 以前为什么弹 |
|---|---|
| **什么都没选中就按 Ctrl+C** | 这条路把"空"也当成一次唤起 —— 立刻弹一条空横条，然后等 900ms 看有没有"迟到的复制"补进去。手滑、或只是想复制，屏幕上就冒出一条空条 |
| **拖选复核时拿"屏幕识别"当证据** | 复制 / 系统接口都没拿到文字时，退化成"看看屏幕上有没有字"。可**屏幕上有字**和**你选中了它**完全是两件事：拖滚动条、拖画布、拖窗口边缘，只要落点附近有文字就可能被认出来 |

## 现在的行为

开着「通用 → 触发 → **没取到文字就不弹**」（默认开）：

- **拖选**：只认"复制 / 系统接口真的拿到了文字"。拿不到就当没选中 —— 不再拿屏幕识别顶替；
- **Ctrl+C**：先不弹。等这次复制真落地，**有字才弹**（远程桌面 / 剪贴板管理器那种慢半拍的复制照样接得住，只是横条晚 0.9 秒出现）；没字就什么都不做；
- 拖滚动条、拖画布、拖图片、空按 Ctrl+C —— 都不会再冒空条。

关掉这个开关：恢复老行为（拖一下就弹空条、Ctrl+C 立刻弹），自绘界面 / 游戏那种"复制不通"
的地方还能靠它去点「识图 / OCR」。

设置项名字也从「划选没取到文字就不弹」改成 **「没取到文字就不弹」** —— 它现在覆盖两条路，
名字里不该再写"划选"。

## 顺带

软件内「**版本历史**」之前最新一条停在 `v1.5.16`，与实际功能严重脱节（用户指出的"帮助页面没更新"里就有它）。这版补了 v2.23.8 一条，写清本轮改动以及前几版的框选改造、万能框选、快捷键独占。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> ⚠ 如果软件正在运行，Windows 会拒绝覆盖。先退出（托盘右键 → 退出），再替换。
