# Quick Achieve v2.23.84

> 「磨砂强度」现在真的能糊住桌面了：磨砂样式改为抓屏 + 着色器模糊，
> 不再依赖 CSS backdrop-filter（它在透明悬浮窗里根本糊不到桌面）。

## 一、根因：磨砂只"糊"了空气

- 「磨砂」原来用 CSS `backdrop-filter: blur()`；
- 横条是**透明悬浮窗**，`backdrop-filter` 取样的是**页面自己的背后**（空的），
  不是桌面 —— 所以强度怎么调，背后内容都清晰；
- v2.23.83 把底板调成半透明后，反而更明显地"看穿"了横条。

## 二、真磨砂：抓桌面 → 模糊 → 画进横条

- 磨砂样式复用「液态玻璃」那套已经成熟的管线：
  Rust 在横条上屏前抓下它背后的桌面 → 前端上传成纹理 → WebGL 着色器模糊；
- 磨砂模式只保留"模糊"：折射 / 色差 / 倒角 / 高光全部归零，
  观感是一块真正的磨砂玻璃，不是液态玻璃的折射效果；
- **磨砂强度 0–32 现在每一档都看得出差别**（0 = 不糊，32 = 重度雾面）；
- 模糊核从 16 个**随机**采样改成 20 个**黄金角螺旋**采样：
  同半径下覆盖更均匀，画面是平滑雾面而不是"雪花屏"。

## 三、「底板透明度」语义统一

- 磨砂样式下，磨砂层始终**不透明地替掉桌面**（不会露出清晰的桌面），
  所以：
  - **100** = 完全透出磨砂背景（纯磨砂，最"透"）；
  - **55**（默认）= 磨砂背景 + 主题底色各一半；
  - **0** = 实色主题底板（完全不透）；
- 这个滑块拖的时候画布**立即重绘**（修复了 `dirty` 未参与重绘判据的问题）；
- WebGL2 不可用时退回**实色底板**：宁可看不到桌面，也不露出清晰的桌面；
- 面板 / 右键菜单照旧实色，不跟着磨砂。
