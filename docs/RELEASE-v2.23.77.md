# Quick Achieve v2.23.77

> 修复「复制链接后，横条里看不到/找不到直达链接图标」：复制链接现在会
> 直接弹出一条带「打开直达链接」按钮的横条，并把这个按钮换成高对比度
> SVG 图标。

## 一、复制链接 → 直达条

- 新增 **复制链接后弹直达条**（默认开，设置 → 通用 → 触发 可关）：
  `Ctrl+C` 复制到的内容确实是网址时，自动弹出横条；普通文字、图片、
  文件复制仍然完全不打扰。
- 识别覆盖：
  - 纯链接 `https://v.douyin.com/70NAaFJGzWg/`；
  - 抖音分享文案里夹着的链接（前后有中文、空格、标点）；
  - 剪贴板里的链接归属校验仍按“按下 Ctrl+C 时的前台程序”，不会把
    别的程序刚写的内容当成这次复制。
- 横条里的「打开直达链接」按钮改用内联 SVG 链条图标 + 强调色，
  不再依赖系统 emoji 字体（以前在部分深浅主题下几乎看不见）。
- 前端增加 URL 兜底：即使后端 `extract_links` 被零宽字符/断行干扰，
  只要当前文字里出现 `http(s)://`，按钮也会亮；点击时后端再解析一次。
- 迟到补字会把 `ocrOnly` 复位，图片识别形态不会再把链接按钮藏掉。

- 右击菜单的「复制链接」如果应用没有发送 `Ctrl+C`，不会触发直达条；
