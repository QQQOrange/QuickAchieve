# Quick Achieve v2.23.22

> 横条 / 网格页（最常用的界面）系统审计后的一批修复 —— 都是能直接撞上的。

## 一、看完收藏夹再回「更多引擎」，引擎列表消失了

`renderPanel` 有渲染指纹缓存：指纹没变 + 面板里已有 DOM 就直接 return。
收藏面板把面板内容换成了收藏 DOM，却**不动指纹** —— 于是"先看收藏夹、再点 ⋯ 回引擎面板"时
签名和上次一模一样，引擎格子一个都不重建：

- 收藏夹内容挂在没有 `.fav-mode` 的面板里；
- 引擎列表凭空消失，再点 ⋯ 也救不回来（指纹仍然没变）。

现在进收藏面板时把指纹清空。

## 二、「按应用专项横条」上拖动排序永远失效

拖动算 `before` 用的是 `CONF.barList`（默认横条），而渲染用的是 `barList()`
（会按应用专项整份取代、按 ocr/trans/img 总开关过滤、末尾再归一化）。
专项横条下两者长度多半不等 → 直接判"已回滚"，图标每次都弹回原处。

现在 `before` 和渲染同源。

## 三、拖出横条移出之后，横条永久带一圈红框

`qs-removing`（CSS 里那圈红边）只在 pointerup 的成功分支里摘 ——
"拖出去松手 = 移出"走的是另一条分支，先 cleanup 就 return，于是红框**永久**挂着，
本次运行内每次弹出横条都带红边。现在 cleanup 里一并摘掉。

## 四、网格编辑态没退出时，隐形抓手留在文字横条上

三个缩放手柄是 `opacity:0` 但**可命中**的透明层。编辑态没退出就被 Esc 收起之后，
它们会留在文字横条上：鼠标划过边缘出现 ns/ew-resize 光标，在那儿拖一下
**就把网格格子尺寸写进配置**（你根本没进网格页）。现在退出网格时一并摘掉，
并且加了"必须在网格编辑态"的守卫。

## 五、包裹符号菜单不再被"无操作自动收起"打断

包裹菜单是 `#bar` 的**兄弟节点**，鼠标停在它上面时不算"悬停横条"，
于是 5 秒无操作到点就把横条连菜单一起收走。现在它在白名单里。

## 六、Ctrl+C 迟到补字后，📁 / 📄 按钮不刷新

在资源管理器里复制一个文件，横条首帧可能是上一轮剪贴板内容，真文字由 `qs://text` 补上 ——
但那条通道只同步"链接/包裹"两组，**没同步路径按钮**：新文字是路径时 📁/📄 不出现
（功能等于失效），上一轮是路径时两颗按钮带着旧标题留着，点下去必然"打开失败"。

## 七、收藏条目点击后 520ms 的定时器会收掉"新一轮"横条

点一条收藏（开始往目标软件粘贴）→ 半秒内又用 Ctrl+C 叫出新横条 →
定时器到点把新一轮的横条和面板一起收掉。表现是"刚弹出就没了"。现在带会话序号。

## 八、其它两处

- 跨页拖动失败时若已退出网格态，不再把 `gridOn` 重新置 true 并在屏外画空网格；
- `qs://text` 里"横条已收起就别改"的守卫用的是 `barEl.hidden`（全文件从没置真），改成语义正确的 `barVisible`。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> 从 v2.23.10 起，换上新 exe 后程序会**自己接管**（每 20 秒看一眼磁盘上的版本号，空闲时自动重启）。
