# Quick Achieve v2.23.102

> E2E 增加第四个场景「设置页搜索」，并让「移远收起」在指针被外部移动时
> 干净跳过，不再把环境干扰报成产品失败。

## 一、新场景 search（9 条断言）

在真实 Main 窗口 + 设置页里走一遍用户最常用的路径：

| 断言 | 说明 |
|---|---|
| 设置页有搜索框 | `#setSearch` 存在 |
| 输入「磨砂」 | 触发 `input` |
| 结果列表出现 | `#setSearchList` 可见 |
| 结果里有「磨砂强度」 | 索引确实建出来了 |
| 点搜索结果 | 派发 `mousedown` |
| 跳到了磨砂强度所在分页 | 可见分页里确实有 `#s-barBlur`（不猜分页 key） |
| 结果列表收起 | 点选后关闭 |
| 动作「导出配置备份」可被搜到 | 命令面板轻量版 |
| Esc 收起结果列表 | 键盘关闭 |

故意不点「导出配置备份」本身 —— 那会弹系统文件框，E2E 不碰真实文件。

## 二、away 场景的环境隔离

「指针没动不收起」这个断言的前提是**指针真的没动**。当前远程会话里
`SetCursorPos` 会失败，或用户/系统在等待期间移动指针；旧逻辑只 skip 一条
断言，后面的「移开」和日志断言会被带偏，最终报成场景失败。

现在遇到下面两种情况直接**整场 skip**（其余场景照跑）：

- 等待期间指针位置偏离起点 >2px；
- 横条已收起且日志里出现「指针移动 ≥6px」。

产品逻辑本身不改。
