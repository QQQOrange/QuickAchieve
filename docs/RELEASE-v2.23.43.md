# Quick Achieve v2.23.43

> 这一版分两层：**把地基补牢**（CI、clippy 门槛、性能基线）+ **加一个你每天都会用到的功能**（本地答案）。

## 一、本地答案：划词内容能算就直接给结果 🆕

以前复制一个 `12*(3+4)`、`5km`、`37C`、`#3B7DFF`，还得开浏览器搜一下。现在横条会多一颗按钮，**按钮上直接显示结果**，点一下复制并收起横条。

| 输入 | 输出 |
|---|---|
| `12*(3+4)` / `2^10` / `sqrt(16)` / `2 × 3` | 算式结果 |
| `0xff` | `255（0xFF）` |
| `5km → m` / `1.5 GB → MB` / `2 h → min` / `1 kg → g` | 单位换算 |
| `37C` / `212F` / `300K` | 温度换算 |
| `2026-11-04` | 周几 + 距今天数 |
| `#3B7DFF` | RGB + HSL |
| 10 / 13 位时间戳 | 日期时间 |
| base64 / `%E4%B8%AD` | 解码结果 |

**判据故意严格**：形态不明确一律不算（`2026` 这种纯数字、`2026-13-01` 这种非法日期、普通句子都返回空）。因为给错答案比不给更糟——用户会照着错的复制走。跨类单位（`5 km → kg`）也直接拒绝。

## 二、设置搜索：拼音首字母 + 最近改过的

- 输入 **`zdsq`** 能搜到「自动收起」：每行标题转成拼音首字母串，查询按**子序列**匹配（复用引擎库已有的 ICU 拼音排序器，不引任何表）。结果排序：标题命中 > 正文命中 > 拼音。
- 搜索框空着时列出**最近点过的 5 项**（存 localStorage，不进配置、不跨机同步）。
