# Quick Achieve v2.23.50

> 横条上的「⋯ 更多引擎」按钮**拿掉了**，改成**右键横条**出「更多引擎」页。

## 交互改动

| 操作 | 结果 |
|---|---|
| 左键横条上的引擎 | 照旧搜索（没变） |
| **右键横条空白处** | **展开「更多引擎」页**（新） |
| 右键某颗引擎 | 还是那颗引擎的菜单（换图标 / 固定到横条） |
| 右键已展开的面板 / 菜单 | 只收菜单，不重开面板 |
| 面板开着时再右键横条 | 保持原样（不重建、不跳回顶部） |

## 为「不出布局 / UI 错乱」做的三件事

1. **不重复渲染**
   面板已经开着时再右键直接返回。`togglePanel(true)` 会重建面板 DOM —— 用户的滚动位置和筛选状态都会被重置，看起来像"面板自己跳回顶部"。

2. **不会撑成收藏面板的尺寸**
   右键入口和原来的按钮共用同一个 `openEnginesPanel()`，里面先清 `panelFav`。否则引擎面板会顶着 `fav-mode` 的宽高规则被撑满整屏（这个坑 v2.23.22 踩过一次）。

3. **尺寸仍然自动收敛**
   横条尺寸由 `ResizeObserver → layout_bar` 实时测量，少一颗按钮横条自然变窄、窗口跟着缩。**没有任何写死的宽度**需要同步改。

## 两个刻意的取舍

- **没用 `hidden` 属性**，改用 CSS `display: none !important`：`.ico` 自己有一套 `display` 规则，属性选择器的优先级压不住它，会偶尔闪一下。
- **没加** `title="右键查看更多引擎"`：横条每次划词都弹，鼠标停一下就冒一个原生 tooltip，会挡住下面的面板。入口说明放设置页帮助里更合适。
