# Quick Achieve v2.23.24

> 修一个我自己在 v2.23.10 引入的回归；另外做了一次运行时压测，确认横条没有泄漏。

## 一、便携版不该去弹 UAC

v2.23.10 为了修"开关显示开、实际不提权"，把启动时的提权判断改成无条件跟随
`auto_elevate`（默认 true）。但那对**便携测试版**是错的 —— 这个构建
（`QS_LITE_PORTABLE = true`）设计上就不提权（互斥体带 `-lite` 后缀、注入事件也放行）。
改完之后全新便携版第一次启动就会弹 UAC。

现在分开处理：

- **行为**：便携版恒不主动提权，正式版跟随配置；你明确拨过开关（`elevate.pref` 存在）时
  永远按你说的办；
- **显示**：设置页拿到的是**真实生效值**，开关不再骗人；
- 设置说明补了一句"便携版不主动提权，默认是关的"。

## 二、运行时压测（这轮没改代码，只验证）

用内置 `--stress` 模式反复 show/hide 横条 **200 次**：

| 指标 | 结果 |
|---|---|
| 端到端 show_bar → 窗口可见 | 25~47ms，平均 **30.5ms** |
| 内存（工作集 / 私有） | 37.2→42.5MB / 11.4→12.3MB（**无增长趋势**） |
| 句柄 | 337 → 366~419 后**平台化**（不是线性泄漏） |
| GDI / USER 对象 | 14→16 / 29（恒定） |
| JS 报错 / 回滚 / 超时 | **0** |

结论：横条的显示/隐藏路径在当前版本下没有泄漏、没有报错，延迟稳定在 30ms 量级。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> 从 v2.23.10 起，换上新 exe 后程序会**自己接管**（每 20 秒看一眼磁盘上的版本号，空闲时自动重启）。
