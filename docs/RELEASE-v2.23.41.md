# Quick Achieve v2.23.41

> 功能 + 体验 + 结构三条一起动：**设置项搜索**、**托盘版本号与日志入口**、**英文覆盖纳入发布门槛**。

## 一、设置页「搜索设置项」（新功能）

设置页有十来个分页、上千行说明 —— 想找"顺带把横条收起"或"清空剪贴板"原来只能翻。

现在顶栏中间有搜索框：

- 输入即筛（标题和说明文字都能搜到），结果显示**标题 + 所属分页**；
- `↑` `↓` 选择、`Enter` 跳过去、`Esc` 关闭；
- 跳过去会自动切到那一页、把这一行滚到视野中间并**闪一下**；
- `Ctrl+F` 直接聚焦搜索框。

索引只收静态的「设置行」（引擎/收藏列表会被配置广播重建，但设置行不会）；万一元素被换掉，跳转时按标题文字重新查一次。

## 二、托盘菜单：版本号 + 打开日志

- 菜单底部多一条**纯信息项**：`版本 2.23.41 · 已就绪` —— 报问题时不用再打开设置看版本；
- 新增「**打开日志文件**」：直接在资源管理器里选中 `log.txt`（不存在就打开数据目录）。让人去便携目录里翻日志的成功率实在太低。

## 三、「英文覆盖」进发布门槛（结构）

新增 `tools/check-all.js`：一条命令跑完 **UI 金丝雀 / 页面冒烟 / 命令表一致性 / 英文覆盖**，任一失败即非零退出。`release.ps1` 现在会跑它。

原因很具体：英文覆盖原来只是"偶尔手动跑一次"，而 v2.23.36 那次整块漏翻（「复制诊断信息」在隐藏分页里）就是这么漏出去的。允许的残留只有 3 条（语言自称 + 引擎名两处），阈值和理由都写在脚本注释里。

## 四、剪贴板测试不再因"环境占用"误红

三条动真剪贴板的用例，原来在"剪贴板被别的程序占着"时直接失败。这在真人排查时是对的，但会让发布流水线因为一台机器上别的软件占用而红掉。

现在先探一次能否打开，打不开就打印明确的 `[SKIP] 剪贴板被占用（owner pid=…）` 再跳过 —— **不静默通过**，也不假装测过。

顺便查清了本轮那次失败的真实原因：剪贴板被 **DeepSeek Harness 进程**（我运行所在的宿主）占着，`OpenClipboard` 返回 `ERROR_ACCESS_DENIED`（错误码 5）——是测试环境，不是产品问题。
