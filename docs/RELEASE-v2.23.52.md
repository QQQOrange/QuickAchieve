# Quick Achieve v2.23.52

> 修两个问题：**右键偶尔没反应**、**★ 收藏按钮不能换图标**。

## 1. 右键没反应

**根因**：判断"面板开没开"用的是 `panelEl.hidden` 这个属性。窗口被后端直接收掉（Esc / 点别处 / 鼠标移远）时，不一定有代码把属性翻回 `true` —— 下一轮右键就以为"面板已经开着"，走进"什么都不做"的分支，看起来就是右键坏了。

**修法**：

- 新增 `panelShown` 作为唯一状态源，由 `togglePanel()` 维护；
- 每轮 `qs://show` 开头强制复位，保证"新一次唤起 = 面板一定是关着的"。

## 2. ★「收藏这段文字」可以换图标了

**面板开着时**右键 ★：

```
更换这个图标…
恢复默认图标（★）
```

面板没开时右键 ★，还是按你的规则出「更多引擎」页。

实现复用引擎那套图标机制：用伪引擎名 `@favquick` 存进 `overrideIcons`，走 `pick_icon` / `reset_icon` 同一条落库 + 广播链路——不新增配置字段，也不会出现"两套图标存储对不上"。换完立即生效，不用等下次划词。
