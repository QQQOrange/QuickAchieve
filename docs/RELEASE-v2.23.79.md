# Quick Achieve v2.23.79

> 修复横条自动收起失效：横条弹出后，超时没有点击、或指针移远，现在都会
> 按设置自动消失。

## 一、无操作自动收起

- 以前只要鼠标在横条附近轻微移动（`pointermove`）就会把 5 秒计时重新
  推后；鼠标在横条旁边来回移动时，横条可以一直不收。
- 现在只有真正的操作才算操作：
  - `pointerdown` / `pointerup`
  - `wheel`
  - `keydown` / `input`
- 鼠标从横条旁边划过不再重置计时；**指针进入横条**会重置一次，给用户
  完整的点击时间。
- 指针停在横条上但一直不点：5 秒到期后再给 1.2 秒宽限，仍不点就收起，
  不再像以前那样每次到期都重新等 5 秒、永远不收。
- 「更多引擎」面板、右键菜单、包裹菜单打开时仍然不自动收，避免把用户
  正在操作的面板收走。

## 二、鼠标移远收起

- 距离判定仍是「指针到横条窗口矩形的距离超过设置值」，默认 400px；
- 连续离开的确认时间从 1.8 秒缩短到 **0.9 秒**（另有 600ms 首屏宽限），
  移远后能更快收起，不会看起来像没反应；
- 取词补字 / 拖动格子期间仍然暂停这条判断，避免把正在补字或拖拽的横条
  收掉。

## 四、设置

- 「通用 → 触发 → 无操作自动收起」默认 **5 秒**，滑块可调；0 = 不收起；
- 「鼠标移远就收起」默认 **400 px**，滑块可调；0 = 不收起。
