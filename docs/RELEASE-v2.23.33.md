# Quick Achieve v2.23.33

> 去掉每行那颗「编辑图标」按钮；**换完图标会自动进编辑器**。

## 改了什么

按你的口径：**只留「换图标」和「默认图标」**，编辑入口不再单独摆一颗按钮。

六处「编辑图标」按钮全部去掉：

| 位置 | 现在只剩 |
|---|---|
| 横条引擎行 | 换图标 / 默认图标 |
| OCR 行 | 换图标 / 默认图标 / 去掉 |
| 识图（🖼）、收藏哨兵行 | 换图标 / 默认图标 |
| 自定义引擎行 | 换图标 / 默认图标（+ 表单里的「编辑」） |
| 外部软件行 | 换图标 / 默认图标 / 固定到横条 |
| 收藏夹目录行 | 换图标 / 默认图标 |

## 编辑图标怎么进

**点「换图标」→ 选一张图 → 自动打开图标编辑器**（一键消除背景、前后对比、调尺寸）。
不想要就点取消，什么都不改。

这件事**后端一直就是这样做的**：`pick_icon` 在编辑器开关打开时会直接调
`open_icon_edit_win`；编辑器关着时就直接落库替换。所以这次只是删掉界面上那颗多余入口，
后端一行没动 —— 少一条路，也少一处"开关关着却还有按钮"的分叉。
