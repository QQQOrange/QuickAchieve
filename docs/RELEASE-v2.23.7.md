## 这次补的

- **README** 功能表新增 **快捷键独占**（含"系统保留键拦不住"的说明），体积说明更新到 `v2.23.7 / 7.6 MiB`；
- **README.en.md** 把「Region action bar」换成三条：Runs on release / Universal capture / Exclusive hotkeys；
- **软件内 ⑤**：新增一段"想每次框完都自己挑？用**万能框选**" —— 并写明区别：
  **具体功能框完直接干，万能框选框完让你挑**，「复制图片」只在万能框选那条路上有；
- **软件内 ④b**：内置功能清单补上万能框选；
- **软件内 ⑦**：新增"热键撞车了怎么办"整段 —— 独占开关的作用、怎么关、以及
  `Ctrl+Alt+Del / Win+L / Win+Tab` 这类系统保留键为什么拦不住；
- **英文帮助**同步这三处（English 界面看到的就是它）。

> 软件内的帮助是**打包进 exe 的前端资源**，所以只有发了新版才会到手上 —— 这一版就是。

## 安装

1. 下载 `QuickAchieve.exe`；
2. 覆盖你现有的那份（**数据目录 `Quick Achieve data\` 不受影响**）；
3. 双击运行。首次运行没有窗口是正常的 —— 在任务栏右下角托盘区找它。

> ⚠ 如果软件正在运行，Windows 会拒绝覆盖。先退出（托盘右键 → 退出），再替换。
