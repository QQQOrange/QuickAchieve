# Quick Achieve v2.23.85

> 磨砂改成**静态雾面**：不抓屏、不跑 WebGL、不跑逐帧重绘，几乎不吃 GPU；
> 背后内容直接从半透明底板透出来，滚动时自然跟着走。

## 一、为什么改

- v2.23.84 为了让「磨砂强度」真的能糊住桌面，走了抓屏 + WebGL 实时模糊；
- 代价是持续抓屏、上传纹理、重绘，滚动时还要实时跟随 —— 用户口径是
  「不需要实时渲染，只要有一层磨砂效果，下面的东西直接透出来，
  别浪费算力」；
- 所以磨砂改回**纯 CSS 的静态层**：没有抓屏、没有着色器、没有 rAF。

## 二、现在的磨砂长什么样

- 半透明底板（`--qs-bar-fill`，由「底板透明度」控制）+ 一层白色雾面
  （由「磨砂强度」控制）+ 一张**静态细颗粒**纹理（内联 SVG 噪点，
  只栅格化一次）；
- 背后的内容直接透过底板显示 —— 滚动、切窗口、放视频都自然跟随，
  因为根本没有"截图"这回事；
- 观感是「蒙了一层雾的玻璃」，不再是真实模糊，但也不再有任何 GPU 负担。

### 两个滑块的新语义

| 滑块 | 作用 |
|---|---|
| **磨砂强度**（0–32） | 白色雾面有多浓：0 = 不磨砂，32 = 雾面最浓（约 29% 白纱） |
| **底板透明度**（0–100） | 100 = 完全透出背后内容，0 = 实色底板 |

- 两个值都是纯 CSS 变量，拖动时立即变化，不需要重绘循环；
- 0 值的小坑也修了（以前 0 会被 `|| 55` 当成默认 55）。

## 三、液态玻璃

- 「液态玻璃」样式**保持不变**：仍然是可选的 WebGL 真折射 / 抓屏；
- 只有用户主动选它时才会跑，默认/磨砂两种样式完全不碰抓屏和 WebGL；
- 如果之后也想把它换成静态近似，可以再说。
