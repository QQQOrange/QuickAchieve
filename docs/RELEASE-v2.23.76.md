# Quick Achieve v2.23.76

> 这一版集中处理「划词有时不弹 / 弹了没字」「托盘退出不彻底」两条主诉，
> 并把配置备份、导出、迁移里几条会静默丢数据的问题一并修掉。

## 一、划词与横条

- **取词成功但内容与剪贴板旧内容相同时，不再被判成“没选中”**。
  用户刚复制过一段文字、又回去重新选它时，`Ctrl+C` 的序号和 owner 都是目标程序，
  但旧逻辑要求“内容必须变化”，于是横条空白。现在以「剪贴板序号变化 + owner 可信」
  为准。
- **微信识别修正**：`process_exe` 返回的是文件名，旧代码用带路径的
  `ends_with("\\weixin.exe")` 永远匹配不到，导致微信专属的 1.5 秒预算、
  延迟还原和“不吃 5 秒冷却”全部失效。现在按 `Weixin.exe` / `WeChat.exe`
  文件名判断。
- **终端保护补齐**：先弹空条后的补字线程也会检查起点是否为终端；
  完整复制通道在发 `Ctrl+C` 前再次确认前台仍是目标，避免把 SIGINT 打进
  正在跑命令的终端，或把新前台的选区复制回来。
- **补字期间横条不再被“鼠标移远”收走**：在途计数改为原子计数（并发取词不会
  被先结束的一条提前清零），并把“先弹空条 → 取词 → 补字”整段纳入保护；
  补字成功会重置离开计时，默认连续离开 1.8 秒才收。
- **先弹空条后取到的文字不再因“横条尚未完成 layout”被丢弃**：最多等 500ms
  让窗口真正可见；用户期间按 Esc/点别处则按 `DISMISS_EPOCH` 作废本次结果。
- **浏览器/Electron 的整块渲染区不再被当作文字表面**：只认原生 Edit/RichEdit/
  NotepadTextBox/TextBox/Scintilla 或 I-beam 光标，拖动滚动条、图片、空白
  不再先冒一条空横条；同时保留 WinUI/激活时序的第二机会。
- 三击选段不再重复触发两次取词；双击判定改用系统 `GetDoubleClickTime`。
- 黑名单判定改用“按下左键的位置”，并在 Ctrl+A 这类键盘触发时看前台窗口，
  不再被鼠标当前位置或第三方浮层带偏。

## 二、托盘与退出

- 锁屏退出、更新重启、托盘退出统一走 `shutdown_common()`：清理临时图 +
  摘托盘图标；更新重启在**新进程成功拉起后**才摘旧图标。
- 退出 watchdog 只覆盖“清理阶段”，不再用 3 秒硬退砍断最长 5 秒的 WebDAV
  同步；进入事件循环退出后仍有 3 秒兜底。
- `NIM_DELETE` 失败会重试 3 次，成功后才销毁 HICON；失败保留句柄待下次清理。
- 注册 `TaskbarCreated`：Explorer 重启后自动重新挂托盘图标；首次
  `NIM_ADD` 失败也会在 2 秒后重试。

## 三、配置、备份与迁移

- **自定义备份目录在主配置损坏时也能找到**：新增 `backup-dir.txt` sidecar；
  `config.json` 是密文信封、抠不出 `backup_dir` 时用它找回备份。
- **主文件解不开时，用户显式恢复/导入现在能真正写盘**：
  `unlock_after_explicit_restore()` 只在这条明确操作上解除锁写，坏文件此前
  已由 `preserve_broken` 留档。
- `backup.key` 改为原子写，避免断电/占用留下半截钥匙，导致主密文永远解不开。
- 清理冗余数据时，`before-restore` / `before-webdav` 快照按**修改时间**裁，
  不再按文件名字典序把刚生成的恢复前快照优先删掉。
- “仅保留最近 N 份”先用本软件备份命名过滤，再计算保留名额；WebDAV 目录里
  别的文件不会占掉名额、导致自己的备份被多删。
- 导出表补齐网格页、OCR、翻译、外部软件、AI 抠图五组；换机导入不再静默
  回默认，`@app:` 横条项也不会因 `apps` 为空被剪掉。
- `@favquick`（收藏这段文字）补进横条哨兵白名单；增加一次性迁移标记，
  移出横条后重启不会被自动补回。主题 `system → page` 迁移同样改为一次性，
  用户手动选“跟随系统”不会再被每次启动改回。
- 恢复/导入时 `backupDir` 空值不再覆盖本机备份目录。
- 图标编辑器保存/导出按 MIME 去掉 `;base64` 后再推扩展名，JPEG/SVG 不再
  被写成 `.png`。
