# Quick Achieve v2.23.44

> 把上一版"没做完的"里能安全交付的四件做完：**剪贴板历史**、**保存失败可见化**、**搜索里的动作**、**诊断加宽**。

## 一、剪贴板历史（新功能）

**设置 → 附加功能 → 剪贴板历史**。记录你复制过的文本，点任意一条即可复制回去。

**隐私三原则**（界面上也写着）：

1. **默认关闭** —— 打开才记；
2. **只存本机** —— 数据在 `cliphist-data.json`，设置单独存 `cliphist.json`，两者都**不进 `config.json`**，所以**不会**被备份 / WebDAV 同步带出去；
3. 只记**文本**（不记图片、不记文件列表），单条 ≤ 20,000 字，默认留 30 条（可调 5~200），**一键清空**；另有「不落盘」选项（只在内存，退出即清）。

实现要点：800ms 轮询读取（**不在输入钩子里读剪贴板** —— 那会卡住全系统），内容变了才入队，超上限丢最旧的，新的排最前。

## 二、保存失败现在看得见

以前配置写盘失败只弹一次托盘气泡 + 一行日志；没看到就以为设置生效了，重启才发现回滚。

现在：

- 后端记下**具体原因**（磁盘满 / 目录只读 / 被占用）；
- 设置页顶部出现**红色提示条**，写明原因和"重启后会回滚"；
- 诊断文本新增「**配置能否写入**」一行（正常 / 具体原因）；
- 日志尾部从 12 条放宽到 **40 条**。

## 三、搜索框里的"动作"（命令面板 lite）

设置搜索现在不只是找设置，还能**直接执行**：

```
导出 → 导出配置备份（明文）
导入 → 载入配置备份
恢复 → 恢复全部默认设置
诊断 → 复制诊断信息
打开配置目录
```

动作走**原有按钮的点击路径**（导入/恢复要弹确认框，不能有两套行为）。
