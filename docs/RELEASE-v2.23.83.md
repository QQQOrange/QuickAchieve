# Quick Achieve v2.23.83

> 磨砂样式改成**透明磨砂**：底板默认 55% 透明，背后能透出来；新增一颗
> 「底板透明度」滑块，只动横条底板（非图标部分），图标浓淡仍归
> 「横条不透明度」管。

## 一、磨砂 = 透明磨砂

- 「横条样式 → 磨砂」下，横条底板不再是实色，默认**半透明**（55%）；
- 新增滑块：**底板透明度**（0–100%）：
  - **100** = 实色底板（老观感）；
  - **55**（默认）= 透明磨砂，背后隐约透出来；
  - **0** = 完全透明，只剩图标（深色桌面下自己权衡）；
- **只改横条底板**，也就是用户说的「非图标部分」：
  - 图标本身的浓淡仍然由「横条不透明度」控制，两颗滑块互不干扰；
  - 面板 / 右键菜单**不跟着变透**（里面有文字和按钮，保可读）；
  - 「默认」样式不受影响（`barBlur = 0` 时底板仍是实色）；
  - 「液态玻璃」样式也不受影响（它有自己的染色 / 磨砂滑块）。

## 二、设置页

- 磨砂样式下，设置页「横条外观」里能看到新滑块，拖动时右边的磨砂预览
  同步变透明（预览的底板和真身用同一套判据）；
- 滑块值会落盘、跟着配置导出 / 导入 / 备份走。

## 三、实现口径（给后来改代码的人）

- 新增配置 `barBgAlpha`（0–100，默认 55，serde 缺省即 55）；
- 横条底板单独走 `--qs-bar-fill`（`bar.css` 的 `.bar`）：
  - `bar.js` 的 `syncBarBg()` 同时算两条：
    - `--qs-bg-fill`：面板 / 菜单用，始终按原色（实色）；
    - `--qs-bar-fill`：横条用，磨砂样式下乘 `barBgAlpha`；
  - 兜底链是 `--qs-bar-fill → --qs-bg-fill → --qs-bg`，JS 没跑到也不会
    莫名全透明；
- 预览用 `color-mix(... var(--pv-bg-alpha)%, transparent)`，不支持时自动
  落回实色，不会出现"预览突然看不见"。
